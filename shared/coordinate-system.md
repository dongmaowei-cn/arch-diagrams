# 坐标系约定 · 所有图共用

## 全局尺寸

```
SVG viewBox 宽度    = 1080（永远不变）
SVG viewBox 高度    = A 区实际占用 + 60 边距
节点最小 padding    = 14px
节点间最小 gap      = 20px
节点圆角            = 8 (常规·--r-sm) / 20 (胶囊·--r-lg) / 12 (容器·--r-md，见 design-system.md)
节点描边粗细        = 1.5px (常规) / 2.4px (强调) / 2.5px (final state)
```

## A 区起点

各图的"section-label / section-sub"文字一般在 y=20~92。
A 区第一个容器（tier-band / lifeline / lane）从 y=70~100 起。

## 关键约定

1. **节点 x/y 用 10 的倍数**：网格更整齐
2. **同列节点 x 一致**：用 grid 思维布局
3. **同行节点 y 一致**：tier 之间统一节奏
4. **边走直角**（orthogonal routing）：除非时序图，否则别走斜线
   - 直角路径：`M x1,y1 L x_mid,y1 L x_mid,y2 L x2,y2`
   - **连接边必须贴节点边界**：起点/终点落在节点四边的**中点**（上下边中点、左右边中点），**永远不从角部出发**
   - 一条边的**入箭头终点 ≠ 另一条边的出边起点**：请求与回执不要挤在同一个边界点上
   - 箭头尖端要**够到目标边界**（矩形边 / 圆周边），不能悬空 8px+ 停在半空
   - 8-12px 间距**只适用于穿行/非连接线**（在节点上方跨过的线）；贴节点的连接边不适用
   - 时序图例外：消息箭头与 lifeline 保持 ~5px 设计间距，不贴线
   - **曲线/自环必须凸出节点外侧**：弧线/贝塞尔不能"弯进节点身体"（如椭圆圆心算在节点内、弧向左凸进矩形）。edge-check [5] 采样验证
   - **composite-bg 框内节点必须完整在框内**：探出框边（几像素都算）= 布局没对齐。edge-check [6] 验证
   - **边标签不压节点**：edge-label / t-lbl 锚点不得落在节点内部。bus/backbone 线骑线标签（所属边本身穿过该节点）豁免。edge-check [7] 验证
   - **ER 关系线不穿表体**：`.er-edge` 必须正交绕行、走表间走廊，不得斜穿/横穿任何表体（端点本身落在表边界，内部采样 + 3px 容差避开边界点）。edge-check [8] 验证
   - **时序激活条盖住消息**：贴 lifeline 的消息端点（起/终）y 必须在某激活条 y 区间内（±6px，允许箭头在条顶上方 ~5px 设计间距），且端点 x 贴激活条左/右边缘（±2px），不在条中心/lifeline 上。edge-check [9] 验证
     - 激活条语义：**覆盖该 lifeline 上所有消息**（第一条入边到最后一个自环回程），画短了 = "消息落在空 lifeline 上"
     - alt/loop/opt fragment **内嵌在所属 phase 内**（右缘内缩 ~16px 形成嵌套），不独立成 phase
     - 折角注释 note-box **右缘对齐 phase-frame 右缘**；文本不溢出框（mono 10.5px ≈ 6.3px/字符，CJK ≈ 10.5px/字）
5. **数据流方向**：架构图一般 **从上到下**；流程图 **从上到下**；时序图 **从左到右**
6. **状态机建模**：判断分支用菱形 choice；主终态用 `state-final success`（橄榄 ⊙）而非普通矩形（矩形暗示"还能继续走"）；起始态出边 ≥ 30px
