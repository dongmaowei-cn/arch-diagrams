提现代发状态机 · 总览

22 节点·4 终态·4 定时 Job

主路径（橄榄加粗）：提现发起 → 分账判定 → -3 待分账 → -2 分账中 → 0 未开始 → 1 代发中 → 2 已提现 —— 由 clearing_server 事务 + 4 个 XxlJob 轮询驱动。

失败路径（rust 虚线）：分账失败 → -1 终态；代发全部失败 → 代发失败终态；已提现后退票 → DISHONOUR。统一「退还扣款 + summary 回滚 + 钉钉告警」兜底。

子状态机：底部 B 区展示批次表 status（TRADING → SUCCESS / PART_SUCCESS / FAILURE）；C 区展示钱包账务 event_type 1~6 全链路流水。

一致性保障：钱包余额/冻结所有变更走 version CAS 乐观锁 + before_change_* 流水留痕，能力收口 ClearingXftWithdrawPayrollWalletService。
