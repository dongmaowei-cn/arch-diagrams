结算单生命周期 · 状态机总览

9 节点·2 终态·3 失败/补偿路径

主路径（橄榄加粗）：待结算 → 结算中 → 已结算 —— 冻结 → 提交银行 → 轮询回执 → 扣减冻结 + 双写账本。

失败路径（rust 虚线）：回执失败 / 超时 → 退避重试（≤3 次）→ 仍失败进 SETTLE_FAILED 终态（解冻 + 人工介入）。

补偿路径：已结算后退款 → 冲正 → REVERSED（写反向账本）。

一致性保障：所有写账本走 version CAS 乐观锁 + 幂等键 settlement_id，双写账本同事务 / 本地消息表。
